# DZMM 这类模型，全网能从哪儿拿到？

> 数据采集：2026-11-10。来源包括 DZMM 公开接口、new-api 中转站公开报价接口、Grandet 价格库、HuggingFace API、OpenRouter API、Civitai API。
> 结论先行：**"同款"只有 3 条路（官方 API / 唯一一家中转 / 逆向，最后一条不推荐）；"同类能力"在开源社区有大量现成权重，14B–27B 级中文 RP 微调多到自己挑。**

---

## 0. 先分清三种"拿到"

| 需求 | 对应路线 | 难度 | 成本 |
|---|---|---|---|
| 就要 DZMM 那几个模型（Nalang / Apex） | 官方 API 或中转站 | 低 | 按积分 / token |
| 要"同档次的中文角色扮演能力"，自己可控 | 开源权重 + 自托管 | 中 | 显卡 or 云 GPU |
| 要"复刻 DZMM 那种自研感" | 开源底座 + 自建 SFT/DPO | 高 | 数据 + 算力 |

---

## 1. 同款：DZMM 自家模型（`nalang-*` / `x-apex-*`）

### 1.1 官方站内 API（唯一"正规"通道）

| 项 | 内容 |
|---|---|
| 准入 | 注册正式账号 → **升到 VIP1** 才能拿 API Token（游客不给） |
| 接口 | **OpenAI 兼容 `/v1`**（Chat Completions，messages 请求体）+ **Card-Chat v2**（角色卡专用：可传角色设定、用户称呼、上下文、多轮消息） |
| 适配 | 官方明确给了 **SillyTavern 基础端点**，可直接接酒馆 |
| 模型名 | 用 `DZMM模型清单.md` 里的 `internalName`，例如 `x-apex-sigma-0621`、`nalang-xl-0826` |
| 计费 | 与网页共用积分（"API 调用消耗账户积分，与网页使用相同计费"） |
| 频率 | 随会员等级：VIP1 50 次/分 → VIP2 100 → VIP3 300 |
| 坑 | 模型名会改会下架（对外展示名和内部分开）；部分档位带严格审核；内容政策随时变 |

### 1.2 第三方中转（全网检索到**只有 1 家**）

| 项 | 内容 |
|---|---|
| 站点 | `aiproxynode.com`，模型分组名就叫 **`dzmm`** |
| 覆盖 | **33 个模型**（nalang-turbo/medium/max/xl + x-apex-surge/dash/pulse/sigma/prism/flux/neo/xl 的各上下文档位） |
| 体系 | new-api（`supported_endpoint_types: ["openai"]`，倍率 `ratio=0.135`） |
| 价格 | 约 **0.27 元/百万输入 token、0.54 元/百万输出**（Grandet 2026-11-06 观察，额度价非现金） |
| 状态 | 比价站标注"运营方待核"——**非官方渠道** |

**Grandet 价格库交叉验证**：`nalang-*` 全家族（17 个名称）+ `x-apex-*` 全家族（17 个名称）**每个都只有 1 条报价**，也就是全网只有这一家中转在卖。顺带还挖到几个**已下架的历史型号**：`nalang-v17-2`、`nalang-xl-16k`、`x-apex-neo`、`x-apex-sigma-0417` —— 说明它模型迭代很快，名字过期很快，要实时拉 `/api/trpc/chat.models`。

> ⚠️ 中转站三大风险：**偷换/降智**（同名不同模型）、**跑路**、以及**违反 DZMM 条款会被封号**。要长期用，走官方 Token 更稳。

### 1.3 逆向 / 抓包（不推荐）

能蹭推理，但拿不到权重，违反 ToS，且随时封；模型名与上游的映射也拿不到。真要做研究，用 1.1 的正规 Token 做行为指纹更有效。

## 3. 商用 API（不想自己托管）

### 3.1 国内厂商（中文最稳、价格低）
DeepSeek、通义 Qwen、智谱 GLM、月之暗面 Kimi、MiniMax —— 都能做长文/对话，价格普遍 0.5–4 元/百万 token，缺点是有平台内容审核，R18 场景基本不可用（这正是 DZMM 这类站存在的理由）。

### 3.2 OpenRouter（公开目录实测 469 个模型）
RP 专用/不审查向的只有少数几个，可作低成本替代：

| 模型 | 上下文 | 输入价 | 输出价 |
|---|---|---|---|
| `cognitivecomputations/dolphin-mistral-24b-venice-edition` | 128K | $0.2/M | $0.9/M |
| `aion-labs/aion-rp-llama-3.1-8b` | 32K | $0.8/M | $1.6/M |
| `undi95/remm-slerp-l2-13b` | 6K | $0.35/M | $0.65/M |

> OpenRouter 的好处是统一计费 + 一个 key 换模型；坏处是 RP 专用模型少、且各家 ToS 不同。

### 3.3 国内中转站（new-api 生态）
几百家在卖"聚合 + 低价"，很多标"逆向/绕过检测"的渠道，**质量和合规都不保证**。要便宜可以试，别把关键业务压上去。

## 5. "大数据检索"方法（这套方法你以后能复用）

1. **扒 new-api 中转站的公开报价接口**：`GET /api/pricing`、`GET /api/models` —— 直接吐出全站模型名 + 倍率 + 分组。我这次就是靠它拿到 DZMM 的 33 个模型名。
2. **比价站反查**：Grandet（`grandet.ai`）按模型名搜，能看到"哪些站在卖、什么价、采集时间"，还能发现下架的历史型号。
3. **HuggingFace API**：`/api/models?search=&filter=zh&sort=downloads&direction=-1` —— 免登录、结构化，比翻网页快。
4. **OpenRouter API**：`/api/v1/models` —— 一次拿到 469 个模型的上下文和价格。
5. **Civitai API**：`/api/v1/models?query=xxx&sort=Most%20Downloaded` —— 画图模型的下载量排序。
6. **站点自身接口**：DZMM 的 `/api/trpc/chat.models` 就是"模型目录"，很多平台都有类似公开端点（tRPC/GraphQL/REST），比解析前台 UI 靠谱得多。

## 6. 建议（按你的目的选）

- **只想用它家模型**：官方 VIP1 Token 最稳（SillyTavern 能直接接），中转只当备胎。
- **想要同等能力 + 自己可控**：`Qwen2.5-14B / Qwen3.8-27B 的中文 RP 微调` + vLLM/SGLang 自托管 + SillyTavern 前端，成本比按 token 买低一个数量级。
- **想复刻"自研闭环"**：照 Peach 的打法——选一个 9B~32B 底座 → 10 万级合成/清洗对话 → SFT + DPO → 量化分发。真正的护城河是**数据与预设体系（世界书、角色卡格式、内容指南）**，不是模型本身。
- **合规**：成人向内容仅限成年人、遵守所在地法律；不要碰未成年人相关；中转站"逆向渠道"有条款与法律风险。
