# 安卓上能装插件（Chrome 扩展 + 油猴）的浏览器，以及开发者面板

## 一、先说结论：不要自己"制造"一个浏览器

编译 Chromium 需要 `depot_tools`、完整源码（约 100GB+）、数十 GB 的中间产物和数小时到数天的构建时间，还要签名、适配驱动与 GPU。这不是手机端能完成的事，我也没法在这个环境里给你打出一个 APK。

**正确做法：用现成的 Chromium 分支**——它们已经做了"扩展支持"这一层改造，且紧跟上游。

## 二、现役可选（Chromium 内核 + 支持扩展）

| 浏览器 | 包名 / 获取 | 特点 |
|---|---|---|
| **狐猴浏览器 Lemur** | `com.lemurbrowser.exts`（应用宝 / Google Play） | 国内可下，明确支持 Chrome 扩展与油猴脚本，中文界面 |
| **Titanium Browser** | `io.github.jqssun.helium`（Google Play） | 开源、基于较新 Chromium，扩展支持可用 |
| **ElixirBrowser** | GitHub `SF-FLAM/ElixirBrowser` | Kiwi 的精神续作，开源可自行编译，扩展支持完整 |
| Firefox | 官方 | 非 Chromium，但扩展生态最完整（Kiwi 停更后的稳妥备选） |

> Kiwi Browser 已停止维护，不建议再作为主力；上面几个是目前的替代。
> 安装扩展：浏览器内打开 `chrome.google.com/webstore` 或拖入 `.crx`；油猴装 Tampermonkey 后导入 `dzmm-helper.user.js`。

## 三、手机上的"开发者面板"三条路

### 1) 页面内开发者面板（最省事，已帮你集成）

在油猴脚本里做了按钮：**DZMM 助手 → ⚙ 设置 → 开发 → 打开移动端开发者面板（Eruda）**。

点击后从 CDN 加载 Eruda，页面右下角出现 `e` 图标，点开即可看到：

- `Console`：日志、执行任意 JS
- `Network`：请求列表、响应体、耗时
- `Elements`：DOM 树、改样式、看属性
- `Sources` / `Resources`：localStorage、Cookie

这相当于手机上的 Chrome DevTools 精简版，任何浏览器都能用（不依赖内核版本）。

### 2) 远程调试（最完整）

1. 手机开「开发者选项 → USB 调试」，连电脑
2. 电脑 Chrome 打开 `chrome://inspect`
3. 手机上用 Chromium 系浏览器打开页面 → 电脑侧点 `inspect`

得到的是**完整 DevTools**（含 Performance、Coverage、Memory）。要求浏览器开了 WebView/Chromium 调试开关，部分国产内核会阉割。

### 3) 抓包视角（看接口最直接）

- 手机 Wi-Fi 代理指向电脑，电脑跑 `mitmproxy` 或 Burp
- 装 mitmproxy 的 CA 证书到「用户证书」；Android 7+ 对 App 默认不信任用户证书，浏览器一般没问题
- 这样能看到每个 XHR 的请求头/响应体，比读 DOM 更清楚

## 四、验证清单（装完自己测一遍）

```js
// 在地址栏输入 javascript: 或 Console 里跑
navigator.userAgent            // 看内核版本
typeof chrome.runtime          // 有值 = 扩展 API 可用
typeof GM_info                 // 有值 = 油猴脚本在跑
```

三个都对，说明这套环境可以跑你的脚本与扩展。

## 五、边界提醒

- 这些工具都是**观察你自己浏览器里的流量**，合法；
- 但拿它们去改第三方站点数据、绕过付费，性质就变了；
- 站点的 `security.txt`（`support@dzmm.ai`，前缀 `[SECURITY]`）是正规披露通道。
