# DZMM 助手（油猴脚本）v1.4

检测到 `dzmm.ai` / `dzmm.io` 后，自动在右下角生成一个**可拖动、可缩放、可调功能**的悬浮窗：模型目录、成本对比、页面探针、内容提取、**页面改造**、数据导出、设置。

- 命中站点 → 自动注入 → **首次自动展开**（每会话一次，可在设置里关）
- 拖动标题栏移动；拖右下角改大小；5 个功能页签可单独关掉
- 深浅主题、透明度、字号、面板宽度、悬浮球大小都能调，设置持久化

**纯前端只读**：脚本不发送任何网络请求，不读写账号凭证，不修改任何服务端状态（没有"改余额/刷积分"这类东西，那属于违法，别在这份脚本里找）。

## 安装

**Android（推荐 Kiwi / Firefox）**
1. 装浏览器：Kiwi Browser 或 Firefox（支持扩展）
2. 装扩展：Tampermonkey
3. 打开 Tampermonkey → 添加新脚本 → 全选删除 → 粘贴 `dzmm-helper.user.js` 全文 → Ctrl+S 保存
4. 访问 `https://www.dzmm.ai/`，右下角出现紫色圆形按钮 `AI`

**桌面 Chrome / Edge**
1. 装 Tampermonkey → 新建脚本 → 粘贴保存
2. 刷新页面即可

> 脚本用 `@match` 限定域名，另外在代码里二次校验 `hostname`，**其他网站不会注入**（有测试覆盖）。

## 提取 → 编辑 → 本地改造

「提取」页签走的是**单页、只读、只改本地**的流程：

```
① 提取当前页内容     抓 <main>/<article> 里文本密度最高的容器（按 文本长度 ÷ 链接数 打分，
                      跳过 nav/header/footer/sidebar/advert 等）
                      → 拆成 h1/h2/h3/p/li/blockquote/pre 块 + 抓 [class*=message] 的对话气泡
                      → 生成带来源与时间戳的 Markdown，填进可编辑文本域
② 改                直接在文本域里改（等宽字体，可拖动高度）
③ 本地预览          点「本地预览改造结果」→ 在自己屏幕上盖一层预览窗，关掉即消失
④ 导出              导出 MD（改写稿）/ 导出 JSON（原始块 + 你改后的 Markdown + 时间）
```

**为什么只做单页、不做全站批量**

- 批量抓别人的角色卡 / 小说是 UGC，涉及著作权和平台条款；
- 站点有 Cloudflare 与风控，批量请求会直接被封 IP / 账号；
- 单页提取已经够用：改你自己的卡、改文案、改设定、导出存档，全都覆盖。

**不做的事**：不写回服务器（预览只在你浏览器里）、不自动发请求、不遍历列表页。

## 页面改造（只改本地显示）

「改造」页签解决的是"这个页面我想改一改"的需求，**改动全部落在你自己浏览器的样式表与遮罩层上，刷新或点还原即恢复，不写回服务器**：

| 能力 | 说明 |
|---|---|
| 字号 / 行距 / 阅读宽度 | 注入一条页面级 CSS（`html{font-size}`、`line-height`、`main{max-width}`） |
| 底色 | 「护眼 / 变暗」用一层覆盖遮罩实现（`pointer-events:none`），不用 `filter`，不会把悬浮窗一起染色 |
| 点选隐藏 | 点「选取元素并隐藏」→ 鼠标划过高亮 → 点一下即隐藏；隐藏项列成清单，可逐条撤销 |
| 自定义 CSS | 直接写规则，例如 `.ad-banner{display:none}`，点「应用 CSS」生效 |
| 还原全部 | 清空样式表、关掉遮罩、清空隐藏清单 |

改造相关的状态（字号、遮罩、隐藏清单、自定义 CSS）都记在 `prefs.page` 里，随 localStorage 持久化。

> 这里"改造"的边界很明确：**改的是渲染结果，不是数据**。想真正改站上的内容，用自己的账号走官方编辑功能保存。

## 交互与调节

| 想改什么 | 怎么改 |
|---|---|
| 面板位置 | 拖标题栏 |
| 面板大小 | 拖右下角把手，或设置里拖「面板宽度」滑块 |

## 交互

- 点悬浮按钮开关面板；`Alt+M` 全局开关；`Esc` 关闭
- 拖动面板标题栏可移动，位置与开关状态存 `localStorage`
- 点击任意模型行 = 复制内部模型名（可直接粘到 API 的 `model` 字段或 SillyTavern 里）

## 数据从哪来

来自 DZMM 的公开接口 `GET /api/trpc/chat.models`（无需登录），快照时间 **2026-11-10**，共 52 条 / 18 个档位。
站点会改名、下架、上新，所以脚本内置的快照会过期。

**更新数据**（离线，不联网）：

```bash
# 用之前抓好的快照
python3 tools/update-data.py

# 或指定新的 JSON（格式见 tools/update-data.py 顶部注释）
python3 tools/update-data.py path/to/models.json
```

脚本会把 `MODELS` 数据块原地重写，其余代码不动。

## 边界与风险

- 只改**你自己浏览器里的显示**，不影响服务端，也不影响别人。
- 站点若改版（DOM 结构、类名、接口），悬浮按钮可能被遮住或探针失效——脚本用 Shadow DOM 隔离样式，抗改版能力较强，但不保证永久可用。
- 使用第三方站点请遵守其服务条款；本脚本不涉及任何绕过付费、篡改数据、自动化刷量的行为。
- 单价系数是站内计费单位，**不是人民币**，仅用于档位之间横向比较。
